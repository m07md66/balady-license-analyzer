# 🏗️ أداة تحليل رخص البناء ودراسة الجدوى

تطبيق ويب تفاعلي يستخرج البيانات تلقائياً من ملفات رخص البناء (PDF) ويقدم تحليلاً هندسياً ومالياً مبسطاً لتوزيع المساحات ومؤشرات الجدوى.

## 🚀 الخصائص
- استخراج مساحة الأرض، الاستخدام (تجاري/سكني)، عدد الأدوار، وعدد الوحدات.
- حساب مساحات البناء المتوقعة والمساحات القابلة للبيع.
- تقدير تكاليف البناء والعوائد الاستثمارية.

## 🛠️ كيفية التشغيل المحلي
1. ثبت المكتبات عبر:
   `pip install -r requirements.txt`
2. شغّل التطبيق عبر:
   `streamlit run app.py`
